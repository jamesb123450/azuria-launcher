## Changes

- Added a selected-instance overview with Minecraft and loader details, a clear Edit instance action and an explicit unavailable launch state.
- Refined library cards with smaller icons, readable names and an actions menu for copying settings or removing an instance.
- Simplified sorting and filters into a collapsible panel while keeping active filters visible and removable.
- Prioritised account information, made the account/setup sidebar collapsible and reduced repeated setup and development information.
- Improved supporting-text readability and contrast across the library, Discover, Settings and instance setup in dark and light themes.
- Distinguished active navigation, selected instances, pressed controls and keyboard focus, with reduced-motion support.
- Improved narrow-window layouts and checked empty, single-instance and populated libraries in both themes.
- Refreshed the public README and removed unused documentation and old screenshots.
- Prevented later main-branch commits from cancelling an active build or release.

## Update information

Install through Settings → Update & restart when the release is published.

Saved instances, accounts and the database schema are unchanged. Discover remains a fictional catalogue preview with installation disabled. Minecraft Services application access remains pending review; game installation and launching are still in development.
