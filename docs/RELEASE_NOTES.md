## Update information

Install through Settings → Update & restart. Windows may briefly retain the previous icon in its shortcut or taskbar cache; reopening the launcher or recreating a pinned shortcut can refresh it.

This is a development release. Microsoft sign-in, game installation and Minecraft launching are not implemented yet.
