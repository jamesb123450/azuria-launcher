# Bundled Azuria Capes

`azuria-capes-0.1.0.jar` is the Fabric 1.21.1 preview from
[Azuria Capes PR #100](https://github.com/jamesb123450/azuria-launcher/pull/100),
built from commit `7d3f901ea8ec3a7c8eb5efb18d663f46da78c317` with JDK 21 and
Gradle 8.12.1. Its SHA-256 is
`a3cc76cdceac23cca7f5fc2b3c13f79782d40275f5ebc54d98d4c97f304990f6`.

The Windows launcher installs it during preparation for Azuria-enabled profiles.
Update the version constraints and the bundled artifact together when adding
support for a different Minecraft version.
