# Friends

- Add friends using their Azuria username.
- Accept, decline and cancel friend requests from the new Friends panel.
- Show friends and pending requests in the sidebar and notifications menu.
- Add remove, block and unblock controls with confirmation for destructive changes.
- Keep friend requests authenticated in the native app and clear cached lists when changing accounts.

This release uses the existing friends database migration. Lists refresh when opened or manually refreshed; live status and messaging are not included yet.
